# Палаброт

Парень человек, калека без правой руки. Состоит в кряже, является помощником Нудо главаря Кража.
Нудо приказал отрубить Палаброту руку, когда тот нарушил запрет, чтобы научить дисциплине.
Эмиссар Рук, по настоянию Нудо, с помощью силы осколка наделил Палаброта талантом мистика.
Палаброт хорошо освоил митсицизм, умеет связываться c эмиссаром через снождение и управлять тенями.
Не любит ни Рука, ни Нудо, не смотря на то положение на которое он был возвышен.
