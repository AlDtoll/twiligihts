# Twilights — статистика по battle log (*_stats.md)

## Цель

По файлу `battle_log_*.txt` собрать **`*_stats.md`** в том же духе,
что `example/rebeld/10/9_sneak/rebeld_9_sneak_stats.md`: краткие агрегаты, средние по пяти типам
очков от совмещения, таблица «ход → время → пять типов → итого».

## Источник правды по формату

1. Прочитай **`RESULT_INTERPRETATION_GUIDE.md`**, раздел 5 (*_stats.md*).
2. Сверься с эталоном: **`example/rebeld/10/9_sneak/rebeld_9_sneak_stats.md`** (заголовок «Кратко»,
   средние, таблица, примечания).

## Откуда брать данные в логе

- **Номер хода** — строка вида `Ход N` (считаются ходы, где дальше идёт блок героя с совмещением).
- **Время хода** — строка `Время хода:<число>` для хода **героя** (в сцене Зевфт/Огра —
  у `Действует Зевфт`), **до** строки `За ход: ...` этого же хода.
- **Очки от совмещения** — одна строка на ход героя:  
  `За ход: пламени: +A, ладрона: +B, зевфта: +C, союзников: +D, концентрации: +E`  
  (имена и порядок в логе могут отличаться по сценам — см. ниже).

Если в `За ход:` **нет** упоминания типа — в таблице для этого типа ставь **0**.

## Соответствие «строка лога → колонка (1–5)»

Зависит от сцены (какие `gemType` у героя). Для **Зевфт / сцена огра** (как
в `battle_log_ZevftOgr.txt`):

| Колонка | Тип в логе   | gemType |
|---------|--------------|--------:|
| 1       | пламени      |       1 |
| 2       | ладрона      |       2 |
| 3       | зевфта       |       3 |
| 4       | союзников    |       4 |
| 5       | концентрации |       5 |

Для **Ребелд / sneak** и аналогичных сцен в логе могут быть подписи **поиск / скрытности /
наблюдения / обстановки / концентрации** — маппинг 1–5 как в `rebeld_9_sneak_stats.md`.

**Правило:** по `HeroStocks` / описанию сцены или по тексту строки `За ход:` восстановить пять имён
и зафиксировать их в шапке stats-файла в блоке «Средние значения по типам».

## Имя и место выходного файла

- Рядом с логом или со сценой, согласованно с `*_results.md` / `*_story.md`.
- Примеры: `battle_log_ZevftOgr_stats.md`, `rebeld_9_sneak_stats.md`.

## Структура `*_stats.md` (обязательно)

1. Заголовок `# статистика <Id>` (короткий идентификатор прохождения или сцены).
2. **`## Кратко`** — буллеты:
    - ходов (число строк таблицы);
    - сумма времени;
    - сумма всех очков совмещения по всем ходам и типам;
    - среднее время хода;
    - финал: строка `FINISH` из лога **или** явная пометка, что в логе нет завершения;
    - при наличии в логе — HP героя и ключевого противника **на момент последней зафиксированной
      записи** (не выдумывать).
3. **`## Средние значения по типам`** — среднее арифметическое **по строкам таблицы** для каждого из
   пяти типов (округление как в эталоне: один знак после запятой).
4. **`## Таблица по ходам (только совмещение)`** — markdown-таблица с колонками: Ход | Время |
   тип1 … тип5 | Итого за ход.
5. **`## Примечания`** — откуда взяты время и `За ход`, что означает «Итого», имя исходного лога.

## Порядок работы

1. Прочитать весь `battle_log_*.txt`, выписать для **каждого** хода героя пару (`Время хода`,
   разобранный `За ход`).
2. Заполнить таблицу; `Итого за ход` = сумма пяти типов.
3. Посчитать агрегаты: суммы, средние по типам, среднее время.
4. Записать `*_stats.md`, сверить суммы вручную или скриптом.
